Ответы на вопросы
Чем Console.Write() отличается от Console.WriteLine()?
Write() выводит текст без перехода на новую строку, а WriteLine() — с переходом.

Что произойдёт, если присвоить int значение 3.14?
Будет ошибка компиляции: нельзя неявно преобразовать double в int. Нужно явное приведение (int)3.14 — получится 3.

Почему 10 / 3 даёт 3? Как получить дробный результат?
Потому что оба операнда int, и деление целочисленное. Чтобы получить дробь, нужно привести хотя бы один операнд к double: (double)10 / 3.

Что означает var в C#?
var — это неявная типизация: компилятор сам определяет тип по значению в момент объявления. В отличие от Python, тип фиксируется и не меняется.
